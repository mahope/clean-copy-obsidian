# Clean Copy for Obsidian

Paste and clean text as proper Markdown inside [Obsidian](https://obsidian.md).

- **Free:** "Paste as clean Markdown/Text" (Ctrl/Cmd+Shift+V) converts clipboard HTML to Markdown using the same engine as Clean Copy for Chrome/Firefox. "Clean selection" tidies the current selection (strips pasted HTML, smart quotes, zero-width characters).
- **Pro ($19/yr):** custom find/replace cleanup rules applied after every conversion, with regex support. Activated with a license key in settings.

## Install (manual / BRAT)

Community-store submission is pending. Until then:

1. Download `main.js`, `manifest.json` from the latest release into `<vault>/.obsidian/plugins/clean-copy-obsidian/`.
2. Reload Obsidian and enable "Clean Copy" in Community plugins.
